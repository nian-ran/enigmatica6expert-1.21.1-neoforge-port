# Enigmatica 6 Expert · 1.21.1 NeoForge 移植版

这是一个非官方、仍在开发中的社区移植项目，将 Enigmatica 6: Expert 从 Minecraft 1.16.5 迁移到 Minecraft 1.21.1 NeoForge。

An unofficial community port of Enigmatica 6: Expert for Minecraft 1.21.1 with NeoForge. The port is still being developed and tested.

## 仓库内容 / Contents

- `kubejs/`：移植脚本、配方、资源和迁移记录
- `config/`、`defaultconfigs/`：整合包配置
- `packmenu/`：菜单资源
- `data/`：实例中的整合包数据资源
- `mods/MODLIST.md`：本机安装的 239 个模组 JAR 文件名清单

本仓库不包含 Minecraft、NeoForge 或第三方模组 JAR，也不是一键安装包。模组清单仅用于记录文件，不是自动下载清单。请从模组作者的官方页面获取模组，并遵循各自的授权条款。

This repository contains source and configuration files only. It does not redistribute third-party mod JARs. The mod list is an inventory, not an automated download manifest.

## 安装 / Setup

先准备兼容的 Minecraft 1.21.1 NeoForge 实例及所需模组，再将本仓库的配置目录复制到实例中。移植内容仍在持续整理；配方和游戏内行为需要继续实测。

Set up a compatible Minecraft 1.21.1 NeoForge instance with the required mods, then copy the repository's configuration folders into it. Recipe registration and in-game behavior still need testing.
